## 2026-11-06. ТЗ v0.3: решения заказчика

Вопросы разобраны по одному. Решения (N-12…N-16 в заметках заказчика):
- Коннекторы llama.cpp, vLLM, OpenRouter, Anthropic, OpenAI обязательны. При сбое модели пауза и уведомление, автоматического перехода в облако нет.
- Библиотеки разрешены; код других агентов в репозиторий не попадает.
- Relay: один общий токен и TLS, работа и через интернет, все агенты свои. Усиление отложено (RLY-090). Часть 06 переписана.
- ОС-изоляции на старте нет, граница проекта задаётся промптом: создавать и менять только в проекте, читать и писать снаружи по разрешению. Усиление отложено (SEC-100), разделы 1–2 части 05 переписаны.
- Описания инструментов вне лимита 3000.
- Рабочая доска роя в агенте, итоги в ZeroAIMemory.
- Память на отдельном постоянном сервере, агент только использует её; при недоступности предупреждение и outbox в SQLite.
- Одна GPU, приоритет: пользователь, задания, арена. Вторая GPU и облако не планируются.
- Бенчмарки: AgentBench FC исключён, SWE-bench Verified разово, FrontierCS 2 в облаке по запросу, General AgentBench как метод.
- Предложения по памяти переданы файлом `docs/memory_upgrade.md`.
- Остальное принято по умолчанию (часть 00, раздел 9).

**Принятый риск.** Без изоляции и с общим токеном ошибка модели или инъекция со страницы может затронуть файлы пользователя и все машины сети. Заказчик предупреждён, риск записан в частях 05 и 06, замер входит в приёмку.

## 2026-11-06. ТЗ v0.2: две независимые проверки

**Проверка исполнителем** (свежий агент прочитал ТЗ как план к реализации): 12 противоречий, 9 пробелов, 3 молчаливо принятых решения. Главное закрыто:
- Автономность против подтверждений: введён мандат задания (SEC-038), запись из tainted-контекста больше не ждёт человека (MEM-077).
- Сетевая политика исследований: сетевой шлюз чтения веба (SEC-047).
- Рой: решает рантайм по декомпозиции модели (SWM-010), работу назначает рантайм (SWM-030), предложения из шины идут через `draft`.
- Снимок памяти вынесен из system в первое сообщение: 3000 токенов теперь выполнимы, а префикс общий между run.
- Приоритет отделён от этапа; появилась R1а (арена-минимум); служба перенесена в R2.
- Спорные решения вынесены в вопросы Q-11…Q-19.

**Сверка контракта с кодом ZAM:** 27 подтверждённых расхождений, часть 04 переписана. Ключевые: `skip_seen` на MCP не передаётся; `Idempotency-Key` не работает у заметок (новый CR-20); `/health` без `features` в `v0.0.10-m5.7`, условие L1 по наличию поля; `data` строгий у `task`, `question`, `idea`; `memory_update_entry`; дайджест показывает только `in_progress` и `blocked`; `session_id` потомка в `brief`; триггеры `keyword` сервер не сопоставляет. Пять выборочных утверждений перепроверены лично по коду. CR-17 снят: маршрут уже в M6.

**Вывод для процесса.** Контракт, собранный по заметкам, содержал 27 ошибок при том, что заметки сверялись с кодом. Контракты с внешней системой обязательно сверять отдельным проходом.

**Ключевые решения автора ТЗ** (полный список в части 00, раздел 5):
