## Детали, которые стоит перенести

**Blast Radius:**
- Измерители по классам команд: `rm -r/-f` — список файлов, число, объём; `git reset --hard` — незакоммиченные изменения; `git checkout -- .`, `git restore .` — неиндексированные; `git clean` — вывод `git clean -n` с теми же флагами; `git push --force` — коммиты на удалённой ветке, которых нет в HEAD; миграции — список ожидающих средствами самого инструмента.
- Учитывает `cd`, `pushd`, `git -C`, подоболочки `( … )`.
- Пути передаются аргументами, а не через shell; имена вида `-delete` не воспринимаются как опции.
- Фокус по умолчанию на «Отмена»; ошибка при измерении означает отказ; одновременные задержки ставятся в очередь, кнопки всегда относятся к показанной команде.
- Модель получает отказ с причиной и может продолжить иначе.

**Savvy Progress:** прогресс воркера, который не отчитывается, показывается заполнением контекста серым; стоимость — оценка по таблице цен, а не счёт.

**Replay Theater:** запись только наблюдает и никогда не задерживает правку; длинные правки ограничиваются коротким diff с одной строкой контекста.

## Общий вывод

Все шесть модов — интерфейс поверх событий агента. У zero-agent журнал событий уже источник истины (D-08), поэтому эти функции ложатся на него без новых механизмов. Новое по сути только одно: предпросмотр последствий опасных команд.
