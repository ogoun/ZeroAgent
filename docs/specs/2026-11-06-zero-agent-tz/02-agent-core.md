# ТЗ zero-agent. Часть 02. Ядро агента

## 1. Цикл агента

Цикл — встроенный граф из узлов `model` и `tools` над примитивами части 01.

```text
сборка запроса → model.stream → нормализация вызовов → проверка политики
      ▲                                                     │
      │              ┌──────────── Interrupt ◄── approval ──┤
      └─ результат ◄─┤ выполнение через Effect ◄────────────┘
                     └─ границы шага: control, bus, напоминания, бюджет
```

| ID | Требование | Приор. |
|---|---|---|
| CORE-101 | Цикл работает до `finish` (worker, orchestrator), финального ответа (top), прерывания, исчерпания бюджета или команды control | P0 |
| CORE-102 | Границы шага: применение `correct`, чтение почты шины, вставка напоминаний, проверка бюджета, запись снимка. Всё в append-режиме | P0 |
| CORE-103 | Сообщения пользователя во время работы: очередь с режимами `queue` (следующий шаг) и `interrupt` (сразу) | P0 |
| CORE-104 | Пакет вызовов: чтения параллельно при поддержке провайдером, мутации строго последовательно. Харнесс вправе сериализовать | P0 |
| CORE-105 | Прерванный ход дополняется синтетическими результатами незавершённых вызовов, чтобы история оставалась валидной | P0 |
| CORE-106 | Режимы работы run: `read-only`, `plan`, `ask`, `accept-edits`, `auto`. Режим меняет политику и инструменты рантайма, а не текст промпта | P0 |
| CORE-107 | Plan mode: агент пишет план, пользователь утверждает, хэш плана фиксируется; далее approve-once автономия с паузами на риск | P1 |
| CORE-108 | Goal-цикл: цель и критерий замораживаются при старте, исполнитель не может их изменить, завершение подтверждает независимый оценщик | P1 |
| CORE-109 | Handoff: экспорт состояния run в компактный документ и продолжение другой моделью, другим агентом или на другом узле | P1 |
| CORE-110 | Resume после сбоя и по команде; `<state>` содержит сделанное, неизвестные исходы, накопленные правки | P0 |

## 2. Управление контекстом

### 2.1. Порядок сборки запроса

Статичное идёт раньше динамичного. Изменение раннего байта инвалидирует всё следующее (R08).

| № | Блок | Стабильность |
|---|---|---|
| 1 | `tools[]`: канонический порядок, сортированные ключи JSON | Сборка + набор инструментов сессии |
| 2 | Core + блоки tier | Версия сборки |
| 3 | Адаптер семейства модели (0–60 токенов) | Профиль |
| 4 | Overlay режима | Фиксируется на старте run |
| 5 | Сжатый `AGENTS.md` с лимитом | Старт run |
| 6 | Первое user-сообщение: `<env>` (ОС, shell, cwd, дата без времени, tier, бюджет, ветка) и замороженный снимок памяти | Старт run |
| 7 | Append-only диалог | Только дополняется |
| 8 | Напоминания | Добавляются и остаются навсегда |

Блоки 1–5 образуют system и инструменты: они общие между run одного проекта. Снимок памяти вынесен из system, чтобы не ломать этот общий префикс. Динамические данные (остаток бюджета, смена режима, внешние изменения файлов, результаты поиска памяти, план после компакции) идут только в блоки 6 и 8.

### 3.4. Отказы в цикле и реакция харнесса

| Отказ | Детектор | Реакция |
|---|---|---|
| Выдуманный инструмент | Имени нет в реестре | Ошибка со списком ближайших |
| Выдуманные пути и аргументы | Проверка существования | Ошибка с близкими совпадениями |
| Пустой ход | `stop` без вызовов | Один nudge, затем `tool_choice=required` или named `finish` |
| Вызов в content/reasoning | Сигнатуры | MDL-005 |
| Обещание без действия | Нет вызова после заявления | Nudge `make the call now` |
| Повтор A,A,A | Хэш имени и нормализованных аргументов в окне; множества для параллельных вызовов | 2-й раз прошлый результат с пометкой; 3-й запрет; 4-й смена стратегии или `blocked` |
| Цикл ABAB, дрейф | n-граммы отпечатков, нет новых файлов и фактов | Рефлексия одним сообщением, вставка плана |
| Повтор текста | n-граммы в стриме | Обрыв, снижение temperature, `presence_penalty` |
| Бесконечное мышление | Бюджет reasoning | Обрыв по таймауту, затем без мышления |
| `finish_reason=length` на вызове | Флаг | Не исполнять; просить короче, писать по частям |
| Порча JSON | Парсер | Ремонт по схеме, 2–3 повтора, затем сжатие истории |
| Ложный успех | `done` без проверки | Сравнение с журналом: были ли изменения, проверки, коды выхода; возврат |
| Edit-as-replace | Резкое сокращение файла | Write guard, отказ при удалении > X % без флага |
| Преждевременное завершение | Незакрытый план | Возврат открытых пунктов |
| Потеря цели | Нет цели в сводке | Цель и сообщения пользователя закреплены дословно |
| Падение кэша | `cached_tokens` | Алерт, дифф префиксов |
| Застой | Нет прогресса N шагов | `blocked`, отчёт родителю |
| Цикл ошибок инструмента | Счётчик по классу | Экспоненциальная пауза, затем `paused`; никаких бесконечных повторов |
