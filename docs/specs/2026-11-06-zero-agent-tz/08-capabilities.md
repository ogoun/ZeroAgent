# ТЗ zero-agent. Часть 08. Прикладные возможности

Базовый шаблон интеграции: **пак (скилл + политика рисков) + существующий MCP/CLI инструмента**, а не собственный клиент (R04).

## 5. Задания

Единый объект **задание** для расписаний, heartbeat, вебхуков и наблюдателей. Опыт OpenClaw показывает, что отдельный heartbeat приходится потом сливать с заданиями.

```text
Job { id, project, kind, trigger, prompt|skill|script, model_profile, permissions,
      budget, timezone, catchup(latest|all|skip), not_after, jitter,
      concurrency(skip|queue), notify, state, last_run, next_run }
```

| ID | Требование | Приор. |

| SCH-002 | Часовой пояс на задание; ловушки DST покрыты тестами | P0 |
| SCH-003 | Догон: `latest` (по умолчанию, окно 7 дней), `all`, `skip`. Запуск получает `scheduled_at` и `actual_at` | P0 |

## 6. Реестр утилит (N-09…N-11)

### 6.1. Правила создания

| ID | Требование | Приор. |
|---|---|---|
| REG-001 | Сначала поиск в реестре. Новая утилита только при отсутствии подходящей | P0 |
| REG-002 | Python — для инструментальных скриптов. Каждый в своём окружении `uv`: PEP 723, `uv lock --script`, `exclude-newer`. Запрещена глобальная установка и `pip install` в системный Python | P0 |
| REG-003 | Rust — для ресурсоёмких и многопоточных утилит. Критерий: CPU-bound, параллелизм, большие объёмы, распределение бинарником | P1 |
| REG-004 | По максимуму чистые функции: вход–выход без скрытого состояния; эффекты выделены и объявлены | P0 |
| REG-005 | Доказательно работающий пайплайн: утилита публикуется только с тестами или примерами, которые рантайм запустил; результат записан как `evidence` | P0 |
| REG-006 | Установка зависимостей — отдельная фаза, версии зафиксированы lock-файлом | P0 |
| REG-007 | Кэш `uv`, `cargo` внутри проекта или каталога утилит, а не в системе | P0 |
| REG-008 | Контракт валидируется до и после запуска; объявленные эффекты сверяются с журналом | P0 |

| Домен | Подключение | Риск | Что нужно от ядра | Приор. |
|---|---|---|---|---|
| Деплой | Coolify MCP, отдельный read-only токен; запись по approval | Высокий: `GetEnvValues`, Deploy | Редакция секретов, узкие токены | P2 |
| Реверс-инжиниринг | Провайдер: pyghidra-mcp, re-mcp-ghidra или REA; практический выбор сравнением | Высокий: файл враждебен | Контейнер без сети, вывод tainted, настройка рантайма | P2 |
| Игры | Роутер + движок; MCP движка: Unity — официальный (по сторонним данным, с июля 2026 через Unity CLI в режиме `unity mcp`, проверить при реализации) или открытые аналоги; Godot `--headless`, Blender MCP | Средний | Скриншот-доказательство, запуск в редакторе | P2 |
| Дизайн | OpenPencil MCP/CLI headless; Figma опционально | Средний | Внешний бинарник, экспорт + скриншот | P3 |
| PM, маркетинг, SEO | Паки скиллов; Postiz для соцсетей | Средний: публикация | Подтверждение публикации | P3 |
| Почта, мессенджеры | MCP, pairing, allowlist | Высокий: входящие недоверенны | Отправка с подтверждением | P2 |
| Календарь, диск, заметки | MCP | Средний | Отправка с подтверждением | P2 |
| Базы данных | MCP, read-only по умолчанию | Средний | Запись по approval | P1 |
| Мониторинг | MCP | Низкий | Замыкает цикл деплоя | P2 |
| Финансы, юридические | Паки | Высокий | Без автоматических действий | P3 |

**Сознательно не входят в ядро:** телефонные звонки, собственный кошелёк и оплата, память активности экрана, Model Council, Office-плагины, x402. Всё это P3 или вне объёма: риск или низкая ценность для самостоятельного размещения.
