# ТЗ zero-agent. Часть 07. Web UI

UI — единственный основной интерфейс: `zero-agent` поднимает веб-страницу, с которой ведётся вся работа и подключаются другие агенты.

## 1. Стек

| Задача | Выбор | Запасной |
|---|---|---|
| Фреймворк | Svelte 5 + Vite 8, единообразно с ZAM | React + Vite |
| Компоненты | `bits-ui` | — |
| Лента | `virtua` или `@tanstack/svelte-virtual`, выбор по прототипу | Своя виртуализация |
| Редактор | CodeMirror 6 | Monaco лениво |
| Diff | `@codemirror/merge` | `diff2html` |
| Терминал | `@xterm/xterm` 6 | — |
| Граф | `@xyflow/svelte`, mermaid | Только mermaid |
| Живой браузер | CDP screencast | noVNC (MPL) для Xvfb/VM |
| Рендер | dompurify, katex, pdfjs-dist | — |
| Транспорт | SSE + POST; WS для терминала | Один WS с мультиплексом |
| E2E | Playwright | — |

Лимит HTTP/1.1 (~6 соединений): один SSE на вкладку с мультиплексом проектов, при нескольких вкладках `BroadcastChannel`.

## 3. Структура

```text
┌──────┬──────────────────────────────────┬──────────────────┐
│Узлы  │ Лента: чат и действия            │ Панель контекста │
│Проект│ ─────────────────────────────    │ план / diff /    │
│Inbox │ сообщения, вызовы, одобрения     │ файлы / терминал │
│Run   │                                  │ браузер / дерево │
│Задан.│ [ввод, режим, модель, бюджет]    │ агентов/инспектор│
└──────┴──────────────────────────────────┴──────────────────┘
```

## 5. Принципы отображения

- Лента показывает результат первым, детали сворачиваются.
- Запись действия агента содержит команду, код выхода, размер вывода и ссылку на spill.
- Вывод агента рендерится как недоверенный: ссылки подтверждаются, активного контента нет.
- Чужой узел визуально отмечен постоянно.
- Статусы агента не дублируются LLM-сводками: всё строится из событий.
- Уведомления: браузер, опционально PWA push; настраиваются для «нужен ввод» и «завершено».

## 6. Приёмочные критерии

| ID | Критерий |
|---|---|
| AC-UI-1 | Лента с 100 000 событий прокручивается без потери кадров на эталонной станции |
| AC-UI-2 | Обрыв и восстановление соединения не теряют и не дублируют событий |
| AC-UI-3 | Каждое действие управления доступно из UI и показывает ack |
| AC-UI-4 | Сценарии S1–S10 проходятся только через UI в Playwright |
| AC-UI-5 | Страница корректна на ширине 390 px |
