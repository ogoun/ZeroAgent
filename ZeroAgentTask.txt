Проведи полное исследование возможностей. Составь полноценное ТЗ со всеми фичами для разработки собственного агента, максимально широкого спектра возможностей. Агент должен максимально полно использовать возможности памяти из проекта H:\Documents\GitHub\ZeroAIMemory.

Архитектурно:
zero-agent - непосредственно агент
zero-agent-relay - сервис для связи агентов по сети, то есть, если несколько агентов подключены к одному релэй сервису,
 то с любого агента можно получить доступ к любому другому агенту в сети и к его проектам. Легитимность доступа проверяется токеном прописанным на релэй сервисе и в конфигах агентов.
zero-agent - поднимает веб-страницу с которой ведется вся работа. С этой же страницы можно подключаться к другим агентам связанным через zero-agent-relay


Сразу из важного:
1. При создании инструментов для каких либо задач на питоне обязательно делать это в отдельном окружении.
2. Агент работает строго внутри каталога проекта, если ему на сказано явно что он может обратиться к данным наружу.
3. Агент должен быть универсальным, от поиска по инету, до огромных исследований и создания больших проектов, независимо от задачи должен работать максимально эффективно.
4. Агент должен уметь выполнять периодические задания, например, раз в сутки изучать что появилось нового по заданной теме и проводить сравнения решений.
5. UI должен быть в виде веб приложения.

Предварительно, язык разработки rust, персистентность - sqlite.
